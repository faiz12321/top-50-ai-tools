# Contributing

Thanks for helping keep this list accurate.

## Suggesting a tool

Open an issue or pull request with:

1. The tool name and its official link.
2. A short description in your own words. Do not paste marketing copy.
3. What it is best for.
4. Whether it is proprietary, open source or open weight, with the licence if you know it.
5. Why it belongs in a list of 50 and which existing tool it might replace.

## Fixing something

- Broken link, renamed product or retired tool: please open a pull request with a source (the vendor's announcement or help page).
- Avoid prices and version numbers. They go stale quickly.
- Keep claims you can back with an official source.

## Keeping the list at 50

The list stays at 50. A new tool usually replaces a weaker or retired one.
